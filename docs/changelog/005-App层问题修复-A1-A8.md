# 005 - App 层问题修复 (A1-A8)

- **类型**: bugfix
- **严重级别**: P2-MEDIUM
- **日期**: 2026-04-14
- **Commit**: `e9bcd0a`

## 问题描述

SwiftUI App 层存在 8 个问题，包括过期回调覆盖新数据、资源泄漏、循环引用等。

## 修复方案

### SearchViewModel.swift
- **A1**: `performContentSearch` 添加 generation guard，防止过期结果覆盖
- **A2**: `loadMore` 添加 generation guard，防止过期分页数据
- **A5**: 所有 `Task.detached` 闭包添加 `[weak self]`，防止循环引用
- **A6**: `performIndexRefresh` 添加 generation guard
- **A7**: `cacheDir` 中 force-unwrap 改为 `??` 安全回退
- **A8**: `indexChangeTask` 添加 `[weak self]`

### HotkeyManager.swift
- **A3**: 热键处理中从 `NSApp.windows` 过滤掉 `NSPanel`
- **A4**: `deinit` 中调用 `RemoveEventHandler` 防止资源泄漏

## 影响的文件

- `MacEverything/App/SearchViewModel.swift`
- `MacEverything/App/HotkeyManager.swift`

## 测试覆盖

App 层修改通过 Xcode Release 构建验证。
