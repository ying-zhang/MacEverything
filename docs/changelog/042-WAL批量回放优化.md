# 042 - WAL 批量回放优化

- **类型**: performance
- **日期**: 2026-04-15
- **Commit**: `302ebff` (merge), branch commit: `28a89b3`

## 问题描述

`load()` 函数逐条回放 WAL 条目，每条都需要获取 `unique_lock` 并更新 trigram 索引。当 WAL 积累 190K+ 条目时，回放时间超过 15 秒超时限制，导致回放失败并被迫回退到全量扫描，启动时间大幅增加。

## 修复/实现方案

采用内存批量合并策略替代逐条回放：

1. 通过 `exportRecords()` 导出当前索引中的全部记录
2. 在内存中使用大小写不敏感的路径映射合并 WAL 条目
3. 移除 tombstone（删除标记）条目
4. 合并完成后一次性调用 `loadRecords()` 加载最终结果

性能提升：10K 条 WAL 条目从超时降至约 15ms。

- `MacEverything/Core/SearchEngine.h` — 新增 exportRecords() 接口
