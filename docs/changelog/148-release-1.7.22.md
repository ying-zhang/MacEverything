# MacEverything 1.7.22 发布说明

MacEverything 1.7.22 重点改进搜索结果的视觉呈现、文件操作效率和索引持久化可靠性。

## 功能概览

- 新增 Finder 风格的图标结果视图，支持列表 / 图标快速切换、五档缩略图缩放与二维键盘导航。
- 新增文件缩略图，图片会保持原始比例；不支持预览的文件会自动显示系统图标。
- 新增浅色 / 深色 / 跟随系统外观，可分别设置背景色、文字颜色、字体和字号。
- 可在设置中调整列表结果的显示密度，让文件信息看起来更紧凑或更舒展。
- 底部状态栏新增文件大小和修改日期高级筛选，支持预设与自定义范围，并可在空关键词下单独使用。
- 菜单栏新增“复制路径”命令，可通过 `Command-Option-C` 复制最前搜索窗口中选中项的路径。

## 交互与界面改进

- 文件操作和右键菜单收敛为共享实现，列表与图标视图保持一致行为。
- 快速筛选、显示方式和缩略图缩放合并为紧凑的单行工具栏，空结果和扫描期间保留控件位置，减少布局跳动。
- 结果状态移到窗口底部，高级筛选入口提供启用数量反馈和统一禁用态。
- 编辑自定义筛选条件时，会等待输入稳定后再刷新结果；常用预设仍会立即生效。
- 应用程序识别、在 Finder 中显示、移到废纸篓、打开终端和快速查看等操作使用统一语义和错误记录。

## 重要修复

- 输入不完整的大小或日期搜索条件时，应用不再意外退出。
- 提高索引保存与异常恢复的可靠性，降低强制退出或保存失败后丢失最新索引更新的风险。
- 改进内容索引在重启后的恢复和对账，减少返回过期或不一致结果的情况。
- 修复部分大小写混合的目录、根目录和结果较多时的搜索边界问题。
- 修复“跟随系统”无法实时响应浅色 / 深色切换，以及快速滚动时偶发显示过期缩略图的问题。

## 自动化验证

- 快速测试覆盖 WAL 回放与修复、内容索引阈值、查询解析回归、结果交互、高级筛选 token 和网格键盘导航。
- 发布候选应分别通过 arm64 与 x86_64 的 GitHub Actions Release 构建、DMG 验证和本地下载检查。
