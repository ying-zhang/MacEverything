# 146 — MacEverything 1.5 发布说明

MacEverything 1.5 重点改进搜索响应速度、索引内存占用，以及搜索窗口和设置界面的可用性。

## 主要变化

- 搜索结果超过上限时，现在会明确提示结果已被限制，而不是把上限数量显示得像精确总数。
- 主界面的索引文件数后会显示近似索引内存占用。
- 启动时先加载基础记录，让 UI 和 HTTP 状态接口更早可响应，再在后台构建可选搜索加速索引。
- 路径索引改为存储稳定的路径哈希，替代完整路径字符串，在保留重复检测能力的同时降低内存占用。
- 拼音首字母搜索和“加速路径搜索”现在可以分别控制。
- 修正 HTTP API 端口启用逻辑；端口、最大结果数等数字设置支持直接输入，并会校验合法范围。
- 搜索窗口在搜索选项旁增加“设置”按钮，更容易找到配置入口。
- 设置界面的“通用”页增加快捷键和 MCP 集成相关控制。
- 搜索语法帮助和正则表达式帮助集中到“搜索与结果”设置页。
- 菜单栏快捷菜单中，“设置”调整到第二组顶部，并增加“正则表达式帮助”。
- 默认索引文件夹现在会在目录存在时包含 iCloud Drive 和用户的 Public 文件夹。
- 刷新托盘图标，选中的 SVG 源文件保留在 `assets/`，同时保留备用图标和 HTML 预览页便于后续比较。

## 后续代码优化补充

- 结果列表增加快速过滤器，可按文件、文件夹、应用、文档、图片、代码、压缩包筛选；快速过滤导致当前查询为空时会自动回到全部结果，避免误判为搜索失败。
- 增加路径过滤输入框，可在当前结果集内按路径片段二次过滤。
- 结果列表支持扩展名列，扩展名可显示/隐藏、排序，并与名称、路径、大小、修改日期列一起支持拖拽调整列宽。
- Enter 键行为可配置为打开文件或重命名；选择结果后可将焦点切入结果列表，键盘操作更连续。
- Phase 2 后台索引构建增加可靠性保护：后台构建期间的新增/更新记录先进入基础数据，索引切换时统一回放；内存紧张时暂缓 Phase 2 并按指数退避自动重试，待内存释放后再完成构建，避免半成品索引或长期停留在线性扫描兜底。
- FSEvents 监听修复排除路径规范化、回调队列停止竞态和自身缓存事件误触发问题，降低不必要的全量重扫风险。
- HTTP API 支持并发连接，启动时对短暂端口占用进行重试，并限制异常请求体大小。
- RE2/Abseil 依赖准备流程在本地与 CI 中保持一致，发布脚本会验证主应用、MCP 可执行文件和嵌入 dylib 不再引用 Homebrew 绝对路径。
- 发布构建支持分别产出 arm64 与 Intel DMG，并在构建阶段验证二进制和依赖 dylib 的架构。

## 发布检查

- DMG 应使用 GitHub Actions 构建产物；发布产物应包含独立的 arm64 与 Intel DMG。
- 发布前应下载 DMG 进行手动验证。
- 此版本作为 `v1.5.30` 发布到 GitHub Releases。
