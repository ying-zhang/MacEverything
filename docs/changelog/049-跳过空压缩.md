# 049 - 跳过无变更的空压缩

- **类型**: performance
- **日期**: 2026-04-15
- **Commit**: `140d194`

## 问题描述

两个持久化类每 300 秒无条件地重写基础文件并轮转 WAL，即使在此期间没有发生任何数据变更。实际观测到 32 分钟内执行了 6 次空压缩操作，产生大量无效的磁盘 I/O。

## 修复/实现方案

引入 `dirty_` 脏标志机制（`atomic<bool>`）：

- **IndexWAL** 的 `append()` 方法在写入时设置 `dirty_ = true`
- `compact()` 在执行前检查 `isDirty()` / `dirty_` 标志
- 仅当存在实际变更时才执行压缩操作
- 压缩完成后重置 `dirty_ = false`

同时更新相关测试，使其通过 WAL 路径写入数据以正确设置脏标志。

## 影响的文件

- `MacEverything/Core/IndexWAL.h` — dirty_ 原子标志定义
- `MacEverything/Core/IndexWAL.cpp` — append() 设置脏标志，compact() 检查脏标志

## 测试覆盖

- 无变更时 compact() 不执行 I/O 操作的验证
- append() 后 isDirty() 返回 true
- compact() 完成后 isDirty() 重置为 false
- 已有测试更新为通过 WAL 路径写入以触发脏标志
