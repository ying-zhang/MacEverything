# 015 - "Recent Files" 标签徽章样式

- **类型**: feature
- **日期**: 2026-04-14
- **Commit**: `9a1ae3e`

## 问题描述

之前的 "Recent Files" 模式通过对整个搜索结果区域进行橙色着色来指示状态，视觉效果过于强烈，干扰了内容的可读性。

## 修复/实现方案

将整区着色改为仅在 "Recent Files" 标签文字上直接叠加橙色圆角矩形徽章（badge），精准标注当前处于最近文件模式，同时不影响结果列表的视觉清晰度。

## 影响的文件

- `MacEverything/App/` 相关 SwiftUI 视图文件

## 测试覆盖

- 手动 UI 验证：徽章在 Recent Files 模式下正确显示，退出模式后消失
