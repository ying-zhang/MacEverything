# 011 - 最近文件列表橙色背景

- **类型**: feature
- **日期**: 2026-04-14
- **Commit**: `5b1829c`

## 需求描述

用户需要视觉上区分"最近文件列表"和"搜索结果列表"，避免混淆。

## 实现方案

当搜索框为空、显示最近文件列表时，为 ScrollView 添加暖橙色背景色调（6% 不透明度），使用户能直观区分两种列表。背景色调随列表切换以 0.25 秒动画平滑淡入淡出。

## 影响的文件

- `MacEverything/App/ContentView.swift`

## 测试覆盖

通过 Xcode Release 构建验证 UI 效果。
