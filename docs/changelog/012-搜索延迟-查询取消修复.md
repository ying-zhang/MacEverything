# 012 - 搜索延迟：查询取消修复

- **类型**: bugfix
- **严重级别**: P1-HIGH
- **日期**: 2026-04-14
- **Commit**: `e613eb5`（合并 fix/search-lag 分支）

## 问题描述

用户清空搜索框后快速重新输入时感知到明显搜索延迟。根因：`SearchEngine::query()` 内部使用的 `dispatch_apply` 不可取消，过期查询占用所有 CPU 核心直至完成。新查询必须等待线程池可用，导致 UI 可感知的卡顿。

## 修复方案

1. **查询代次取消**：添加原子变量 `queryGeneration_`，每次 `query()` 调用递增。扫描循环每 1024 次迭代检查代次计数器，若发现有更新的查询已到达则提前中止
2. **延迟加载最近文件**：文本清空时延迟 20ms 调用 `loadRecentFiles()`，为过期的 `dispatch_apply` 线程留出退出时间

## 影响的文件

- `MacEverything/Core/SearchEngine.cpp` / `.h`
- `MacEverything/App/SearchViewModel.swift`
