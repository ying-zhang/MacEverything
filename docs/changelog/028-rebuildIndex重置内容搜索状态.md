# 028 - rebuildIndex 时重置内容搜索状态

- **类型**: bugfix
- **严重级别**: P1-HIGH
- **日期**: 2026-04-14
- **Commit**: `062bfb9` (merge), branch commit: `533ff0c`

## 问题描述

调用 `rebuildIndex()` 后，内容搜索（content search）的状态未被重置，导致界面可能展示过期的搜索结果（stale results）。此为审计项 H-3。

## 根因分析

`rebuildIndex()` 重建了文件名索引，但未同步清理内容搜索相关的状态变量。旧的搜索结果在索引重建后仍然保留在内存中，用户看到的搜索结果与实际索引内容不一致。

## 修复/实现方案

在 `rebuildIndex()` 流程中增加内容搜索状态的重置逻辑，确保索引重建后不会残留旧的搜索结果。

## 影响的文件

- 内容搜索相关的状态管理文件
- `rebuildIndex()` 所在的文件

## 测试覆盖

- 验证 rebuildIndex 后内容搜索结果被正确清空
- 验证重建后重新搜索返回最新结果
