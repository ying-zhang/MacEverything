# 149 — 运行时安全与搜索工作流收尾

日期：2026-07-25  
类型：feature

## 功能概览

- 保持 GUI/菜单栏进程作为唯一生产索引引擎；关闭窗口后继续维护索引，明确退出应用才停止。
- 删除未打包的 CLI daemon、构建目标、专属测试及当前文档入口，避免第二套完整引擎与产品运行模型冲突。
- HTTP API 保持回环绑定、Host 校验和 Origin 拒绝；访问 token 改为可选设置且默认关闭。启用后可在设置中查看、编辑或重新生成 256-bit token，文件权限固定为 `0600`。
- 搜索结果支持按所选列导出 CSV/TXT，导出范围包含查询结果上限内的完整结果，而不只包含已分页显示的部分。文件名搜索默认 10,000、最多 100,000；内容搜索提供独立设置、默认且最多 200，GUI 分别按 100/200 条分页。
- `mace` 默认跟随设置页保存的 HTTP 端口，`--port` 仅用于临时覆盖；搜索状态栏和“搜索”菜单均提供导出入口。
- 复用路径二次过滤器增加文件夹选择和最近 5 个目录，支持快速使用和删除历史目录。
- 首次权限体验拆分为“快速开始”和“全盘搜索”；普通文件夹索引不再无条件要求 Full Disk Access。

## 重要修复

- instance lock 获取失败后在加载快照、回放 WAL 或写入索引前终止，并向 GUI 展示可恢复的启动失败状态。
- HTTP token 文件支持递归创建父目录、并发读写锁、严格权限和完整写入检查。
- 空 `Origin:` 与普通浏览器 Origin 一样被拒绝，避免策略声明与实现不一致。
- `batchMutate()` 已按 300 项分块释放写锁；新增 650 项跨分块正确性测试。
- MCP 配置命令增加超时和强制终止保护，避免外部 CLI 卡住设置界面。
- CSV 导出使用 UTF-8 BOM，并转义公式、制表符和回车前缀，避免 CJK 乱码或文件名被表格软件当作公式执行。

## 验证

- C++ HTTP 安全、实例锁和 FSEvents 批量变更测试。
- Swift MCP 配置测试和 Objective-C++ bridge lint。
- Release Xcode 本地构建。
