# 008 - 启动挂起防御

- **类型**: bugfix
- **严重级别**: P1-HIGH
- **日期**: 2026-04-14
- **Commit**: `24fd13e`（合并 fix/startup-hang 分支）

## 问题描述

应用启动时可能无限停留在 "Indexing files..." 加载状态。根因：DirectoryScanner 在遇到 stale NFS/SMB 挂载点时阻塞、WAL 重放耗时过长、`setupContentPersistence` 阻塞主线程等多种情况均可导致 `isScanning` 永远无法置为 `false`。

## 修复方案

实施 5 层防御机制：

1. **DirectoryScanner cancel 机制**：在 worker 线程、CV wait predicate、scanDirectory 循环中添加取消检查点
2. **全局 60 秒启动超时**：使用 `compare_exchange_strong` 单次触发保护
3. **45 秒扫描超时**：超时后调用 `scanner->cancel()` 接受部分结果
4. **内容持久化异步化**：将 `setupContentPersistence` 移至 `QOS_CLASS_UTILITY` 后台队列
5. **WAL 重放 15 秒超时**：超时则放弃 WAL 重放，强制全量扫描

## 影响的文件

- `MacEverything/Core/DirectoryScanner.cpp` / `.h`
- `MacEverything/Bridge/MacSearchBridge.mm`
- `MacEverything/Core/IndexPersistence.cpp`
