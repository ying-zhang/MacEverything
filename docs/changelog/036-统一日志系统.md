# 036 - 统一日志系统

- **类型**: feature
- **日期**: 2026-04-15
- **Commit**: `c760af9` (merge), branch commit: `cf319f9`

## 问题描述

项目跨 C++、Objective-C++ 和 Swift 三个技术层，各层使用不同的日志方式（`std::cout`/`std::cerr`、`NSLog`、`print`），缺乏统一的日志格式、级别过滤和文件输出能力。排查问题时需要在多个输出源之间来回切换，效率低下。

## 修复/实现方案

新增统一的 `Logger` 类，提供以下能力：

- **跨层统一**: 单一日志接口覆盖 C++、Objective-C++ 和 Swift 层
- **文件输出**: 支持将日志写入文件，便于离线分析和用户反馈时附带日志
- **级别过滤**: 支持日志级别（DEBUG/INFO/WARN/ERROR 等），可按级别过滤输出
- **一致格式**: 所有层的日志输出采用统一的时间戳和格式

## 影响的文件

- Logger 实现文件（新增）
- 各层中使用日志的文件（迁移到统一日志接口）

## 测试覆盖

- 验证文件输出功能正常
- 验证级别过滤行为正确
