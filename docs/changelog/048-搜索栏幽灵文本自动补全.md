# 048 - 幽灵文本自动补全

- **类型**: feature
- **日期**: 2026-04-15
- **Commit**: `a00f30d`

## 问题描述

搜索框缺乏历史记录补全功能，用户需要每次完整输入搜索关键词，无法快速重复之前的搜索操作。

## 修复/实现方案

实现基于搜索历史的幽灵文本（Ghost Text）自动补全：

**UI 展示**：
- 在搜索输入框中以 ZStack overlay 方式显示半透明的补全建议
- 使用 `.secondary.opacity(0.4)` 样式呈现，视觉上与用户输入明确区分
- 按 Tab 键接受补全建议

**SearchHistoryStore**：
- 使用 UserDefaults 持久化搜索历史
- 最大容量 200 条记录
- 按前缀匹配，优先按使用频率排序，频率相同时按最近使用时间排序

**记录策略**：
- 输入稳定 2 秒后记录搜索词
- 搜索框失去焦点时记录
- 搜索框清空或输入与建议完全匹配时清除幽灵文本

## 影响的文件

- `MacEverything/App/SearchHistoryStore.swift` — 搜索历史存储与查询
- `MacEverything/App/ContentView.swift` — ZStack overlay 幽灵文本 UI
- `MacEverything/App/GhostTextModifier.swift` — Tab 键接受补全的输入修饰器
