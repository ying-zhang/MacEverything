# 结果显示控件与五档缩放

## 变更概述

- 将列表 / 图标模式切换器从独立工具行移动到快速筛选栏右侧，减少结果区域上方占用的垂直空间。
- 在切换器旁常驻显示快速缩放 Slider，可直接调整缩略图尺寸与网格密度；列表模式或不可用状态下仅置灰，不改变工具栏布局。
- 图标尺寸统一为 `64 / 96 / 128 / 160 / 200 pt` 五档，设置页与快速筛选栏使用相同规则。
- 历史设置中的其他尺寸会自动归一到最接近的档位，默认值调整为 `128 pt`。
- 快速筛选按钮使用紧凑宽度，并移除“应用”选项；应用仍包含在“文件”筛选结果中。
- 无结果或扫描过程中保留显示模式控件的位置，仅将其置灰，避免工具栏跳动。
- 缩略图按原始长宽比缩放到图标方框内，不再强制拉伸为正方形。
- 设置页将“结果行高”明确为“列表结果行高”，固定范围为 `20–120 pt`，不再随字号联动调整。
- “显示缩略图”对新安装默认开启，“图标大小”统一更名为“缩略图大小”。
- 浅色和深色颜色设置合并为单一编辑区，通过明确的模式切换选择编辑目标，并自动选中当前生效的外观模式；“正文色”更名为“文字颜色”。

## 验证重点

- 最小窗口宽度下，快速筛选、路径筛选与右侧显示控件不应重叠。
- 空结果和扫描状态下显示控件应保持原位并处于禁用状态。
- 切换到列表模式时缩放 Slider 保持显示并置灰；切换回图标模式时恢复可用并保留上次选择的档位。
- 拖动 Slider 后缩略图尺寸、网格列数和键盘上下导航列数同步更新。
- 横向或纵向图片缩略图应保持原始长宽比。
- 字号变化不应再自动修改列表结果行高，行高可独立设置为 `20–120 pt`。
- 切换主题时颜色编辑器应自动选择对应的浅色或深色模式，同时仍允许手动编辑另一模式。
