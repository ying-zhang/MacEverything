# 037 - 文件拖放支持

- **类型**: feature
- **日期**: 2026-04-15
- **Commit**: `a0405a0` (merge), branch commit: `26d5ae1`

## 问题描述

用户无法将搜索结果中的文件直接拖放到外部应用（如 Finder、VS Code、Xcode），只能通过右键菜单或双击打开。拖放是 macOS 用户的常见交互模式，缺少此功能降低了使用效率。

## 修复/实现方案

为文件名搜索结果和内容搜索结果两个列表均添加拖放支持：

- 使用 `NSItemProvider` 配合 `NSURL` 提供文件引用
- 用户可从搜索结果行直接拖拽文件到外部应用
- 支持的目标应用包括 Finder、VS Code、Xcode 等所有接受文件拖放的应用

## 影响的文件

- `ResultRow.swift`（文件名搜索结果行）
- `ContentResultRow.swift`（内容搜索结果行）
- 可能涉及的列表容器视图文件

## 测试覆盖

- 验证文件名搜索结果可拖放到 Finder
- 验证内容搜索结果可拖放到外部应用
- 验证拖放提供的 URL 指向正确的文件路径
