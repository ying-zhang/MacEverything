# 019 - 内存优化：节省约 550 MB

- **类型**: performance
- **日期**: 2026-04-14
- **Commit**: `012b1f8` (merge), 分支提交: `25e356e`

## 问题描述

在大规模文件系统（百万级文件）场景下，内存占用过高，主要消耗在路径字符串重复存储、trigram 冗余副本和批量访问时的不必要拷贝。

## 根因分析

- **路径字符串重复**：相同目录前缀在每条记录中独立存储，大量重复。
- **recordTrigrams_ 冗余**：每条记录维护一份独立的 trigram 集合副本，与全局 trigram 索引数据重复。
- **批量访问拷贝开销**：批量读取记录时产生不必要的深拷贝。

## 修复/实现方案

- **PathTable 去重**：引入路径表（PathTable），将相同目录前缀去重存储，记录仅保存路径表索引。
- **消除 recordTrigrams_**：移除每条记录的 trigram 副本，全局 trigram 索引已足够支持反向查找。
- **零拷贝批量访问**：批量记录访问改为引用/视图模式，避免深拷贝。

总计节省约 **550 MB** 内存（百万级文件场景）。

## 影响的文件
