# 030 - 提取共享工具函数（StringUtils / TextHighlight）

- **类型**: refactor
- **日期**: 2026-04-14
- **Commits**: `4bb7d1b`, `19a9ee8`

## 问题描述

`SearchEngine` 和 `ContentIndex` 中存在完全相同的 `toLower` 实现（约 35 行），`ResultRow` 和 `ContentResultRow` 中存在重复的高亮匹配逻辑。重复代码增加维护成本，修改时容易遗漏同步。

## 修复/实现方案

1. **C++ 层**：将重复的 `toLower` 函数提取到共享的 `StringUtils.h` / `StringUtils.cpp`，`SearchEngine` 和 `ContentIndex` 统一引用共享实现。
2. **Swift 层**：将重复的 `highlightMatches()` 函数提取到 `TextHighlight.swift`，`ResultRow` 和 `ContentResultRow` 统一使用共享实现。

## 影响的文件

- `MacEverything/Core/StringUtils.h`（新增）
- `MacEverything/Core/StringUtils.cpp`（新增）
- `MacEverything/App/TextHighlight.swift`（新增）
- `MacEverything/Core/SearchEngine.cpp`（移除重复 toLower）
- `MacEverything/Core/ContentIndex.cpp`（移除重复 toLower）
- `MacEverything/App/ResultRow.swift`（移除重复 highlightMatches）
- `MacEverything/App/ContentResultRow.swift`（移除重复 highlightMatches）

## 测试覆盖

- 验证 toLower 在各调用场景下行为一致
- 验证高亮匹配在文件名搜索和内容搜索结果中表现一致
