# 016 - 搜索栏蓝色边框与字号调整

- **类型**: feature
- **日期**: 2026-04-14
- **Commit**: `0fd53b9`

## 问题描述

搜索栏视觉不够突出，字号偏小（22/24），放大镜图标缺少颜色强调，整体搜索区域的视觉层次需要增强。

## 修复/实现方案

- 为搜索栏添加 2px 蓝色圆角边框，突出搜索区域的视觉焦点。
- 将搜索栏字体大小从 22/24 增大到 26，提升可读性。
- 增加内边距（padding），提供更舒适的输入体验。
- 放大镜图标改为蓝色，与边框风格保持一致。

## 影响的文件

- `MacEverything/App/` 相关搜索栏 SwiftUI 视图文件

## 测试覆盖

- 手动 UI 验证：边框颜色、字号、图标颜色、间距均符合设计预期
