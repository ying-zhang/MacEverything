# 134 - README 重构：用户视角 + 开发者视角双分区

## 变更概要

将 README.md（中文）和 README_EN.md（英文）从混合技术文档重构为双读者视角的产品介绍文档。

## 背景与动机

原 README 将用户功能和技术实现细节混在一起，读起来更像技术文档而非产品介绍。不同读者（用户 vs 开发者）关注点不同，混合呈现降低了两类读者的阅读体验。

## 设计方案

将 README 分为两个明确的部分：

### 第一部分：功能亮点（用户篇）

从使用体验角度介绍功能卖点，吸引下载和使用：

- **极速搜索** — 性能对比表格（MacEverything vs Spotlight vs find）
- **随叫随到** — Option+Space 全局唤起，可自定义快捷键
- **智能输入体验** — Ghost 文本自动补全、语法高亮、搜索选项徽章
- **Everything 风格查询语法** — 常用查询示例 + 可折叠的完整过滤器列表
- **全文内容搜索** — infile: 语法、Trigram 索引加速
- **实时同步** — FSEvents 监控、两阶段即时启动、焦点感知省电
- **交互细节** — 智能高亮、拖放、右键菜单、Cmd+Click、最近文件
- **AI 工具集成** — MCP 架构图、4 个工具说明
- **HTTP API** — curl 示例
- **安装** — DMG / 源码构建 / CLI 守护进程

### 第二部分：技术深度（开发者篇）

从技术架构角度展示项目亮点，吸引 star 和贡献：

- **架构总览** — 三层架构图 + 三种部署模式
- **核心引擎** — 8 个组件的关键设计说明
- **基准测试** — 搜索延迟、Trigram vs 线性扫描、SIMD 吞吐量
- **关键技术** — 14 项技术的 impact 说明
- **测试体系** — 79 个测试模块，覆盖范围
- **项目结构** — 目录树

## 数据更新

- 测试模块数从 77 更新为 79（当前实际值）
- 基准测试平均值从 39.8ms 更新为 10.5ms（R29 SoA 优化后最新结果）
- 新增多项用户功能描述（Ghost 自动补全、语法高亮、搜索徽章、焦点感知省电等）

## 影响范围

- 仅文档变更，无代码改动
- README.md（中文版）— 完全重写
- README_EN.md（英文版）— 完全重写，与中文版结构一致
