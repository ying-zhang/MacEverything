# NAS 同步与启动失败处理修复

**日期**：2026-09-27

## 修复内容

- NAS 轮询只重扫网络文件系统根，不再每 60 秒重建本地索引根。
- 网络轮询增加进行中保护，避免一次 NAS 重扫超过轮询间隔时任务持续堆积。
- 轮询完成状态改为独立共享对象，避免延迟完成回调引用已析构的服务对象。
- 首次扫描遇到不可达根时报告启动失败，保留现有 engine，不创建空索引。
- 重建索引会先验证配置根目录，避免在 NAS 或外置盘未挂载时删除旧索引。
- 混合本地和 NAS 根目录时，本地目录继续回放 FSEvents，NAS 目录使用轮询协调。
- 启动失败界面按不可达目录显示可恢复提示，重建前清除旧错误状态。
- 监控重启保留 FSEvents 事件水位，减少根配置变化期间的事件遗漏。
- 网络文件系统检测支持尚未出现的挂载子路径，通过 mount table 识别最长匹配挂载点。
- HTTP 内容查询支持客户端断开、服务停止和 30 秒截止时间取消。
- 高亮正则增加重复交替保护，并补充嵌套量词回归测试。
