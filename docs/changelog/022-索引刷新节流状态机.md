- **类型**: feature

## 问题描述

焦点感知节流逻辑嵌入在业务代码中，状态转换隐式分散，难以测试和维护，也不利于后续扩展更复杂的节流策略。

## 修复/实现方案

将节流逻辑抽取为独立的 `IndexRefreshThrottle` 状态机类，管理以下状态及转换：

- **Focused**：应用在前台，正常频率刷新。
- **Unfocused**：应用在后台，暂停刷新。
- **Cooldown**：焦点切换后的冷却期，防止快速切换导致频繁刷新。

状态机接口清晰，输入为焦点事件和时间推进，输出为是否允许刷新的决策。
