MacEverything：macOS 快速文件搜索工具（fork自joshua-wu）

2026-08-02https://ying-zhang.cn/misc/2026-maceverything/

MacEverything 是 macOS 的极速文件搜索工具，灵感来自 Windows 上的 Everything。Fork 自 joshua-wu/MacEverything，在搜索速度、查询语法、中文体验、实时索引、AI 工具集成和应用可用性上做了系统改进。

当前版本：1.7.30，提供 Apple Silicon 与 Intel 安装包，并支持 Homebrew Cask 安装。

完整功能列表

搜索与索引

  • 极速文件名搜索 — 面向数百万文件的毫秒级搜索，基于文件名与路径 Trigram 倒排索引。
  • 全盘快速扫描 — 使用 macOS 底层批量文件属性 API 扫描目录树，减少逐文件系统调用开销。
  • 文件名与完整路径同时匹配 — 普通关键词默认同时搜索文件名和路径，支持多个词按 AND 组合。
  • 路径片段搜索 — 支持 `src/main`、`/project/*/target`、`/local/bin/*` 等结构化路径查询。
  • Glob 通配符 — 支持 `*.swift`、`~/Documents/*.pdf` 等常见通配符搜索。
  • 正则表达式搜索 — 支持 `regex:` 查询，并通过 Trigram 预过滤加速候选集生成。
  • 区分大小写、全词、全文件名匹配 — 支持 `case:`、`ww:`、`wfn:` 等精确匹配模式。
  • 最近文件视图 — 搜索框为空时显示最近修改的文件，便于快速回到刚处理的内容。
  • 搜索取消与防抖 — 快速输入时取消过期查询，避免旧结果覆盖新结果。
  • 快速过滤器 — 在当前结果中筛选文件、文件夹、文档、图片、代码和压缩包；过滤后无结果时可自动恢复全部结果。
  • 路径过滤器 — 在结果集内按路径片段继续缩小范围，适合大目录或多项目工作区。
  • 最近目录 — 可直接选择文件夹作为路径过滤条件，并管理最近使用的 5 个目录。
  • 结果导出 — 支持将查询上限内的完整过滤结果导出为 CSV 或 TXT；GUI 分页不截断导出。文件名搜索默认 10,000、最多 100,000，内容搜索独立设置、默认且最多 200。

查询语法

  • Everything 风格查询 — 保留随手输入片段即可命中的体验，并扩展为完整 AST 查询管线。
  • 布尔运算 — 支持 AND、OR、NOT 组合复杂条件。
  • 扩展名过滤 — `ext:swift,h`、`ext:py` 等。
  • 大小过滤 — `size:>1mb`、`size:100kb-5mb` 等。
  • 类型过滤 — `type:file`、`type:folder`。
  • 路径过滤 — `path:`、`nopath:`、`parent:`、`depth:`。
  • 日期过滤 — `dm:` 修改日期、`dc:` 创建日期、`da:` 访问日期，支持 today、thisweek、last7days 和比较表达式。
  • 文件名长度过滤 — `len:>50` 等。
  • 文件类型宏 — `audio:`、`video:`、`pic:`、`doc:`、`zip:` 快速筛选常见媒体和文档类型。
  • Home 目录展开 — 支持 `~` 查询，如 `~/Downloads/*.dmg`。
  • 内置语法帮助 — 应用内提供搜索语法帮助窗口。

全文内容搜索

  • 文件内容检索 — 使用 `content:` 或 `infile:` 搜索文件内部文本。
  • 内容 Trigram 索引 — 为全文搜索建立独立索引，避免每次查询都全盘 grep。
  • 增量内容索引 — 仅重新索引变更文件。
  • 上下文片段 — 内容搜索结果显示命中关键词附近的文本片段。
  • 内容索引设置 — 可配置参与内容索引的文件类型和最大文件大小。

实时同步与启动

  • FSEvents 实时监控 — 新建、删除、重命名和修改文件后自动更新索引。
  • 两阶段即时启动 — 启动时先加载磁盘缓存，让搜索尽快可用，再在后台追赶文件系统变更。
  • WAL 与增量持久化 — 使用写前日志和分页脏页刷新降低崩溃恢复与落盘成本。
  • 自动子树重扫 — 检测事件截断或目录级变化后自动触发必要范围的重扫。
  • 焦点感知刷新 — 窗口不在前台时减少刷新，回到前台后批量追赶，降低后台 CPU 占用。

界面与交互

  • 全局快捷键 — 默认 `Option+Space` 唤出搜索窗口，快捷键可配置。
  • 搜索框自动聚焦 — 打开窗口即可输入。
  • Ghost 自动补全 — 根据搜索历史和系统关键词显示半透明建议，按 Tab 接受。
  • 搜索栏语法高亮 — 过滤器、参数、字符串和运算符使用不同颜色标识。
  • 搜索选项徽章 — 以菜单和徽章切换正则、大小写敏感、全词、全文件名等模式。
  • 结果高亮 — 基于查询 AST 标注命中部分，能处理 glob、正则、大小写和排除条件。
  • 可配置结果列 — 支持名称、扩展名、路径、大小、修改日期列，列可隐藏、排序并拖拽调整宽度。
  • 列表与图标模式 — 快速筛选栏中的控件垂直居中，“显示方式”明确标识布局入口；常驻的五档缩略图滑块在列表模式或无结果时置灰。
  • 结果外观设置 — 列表缩略图默认开启，可将列表结果调整得更紧凑或更舒展；颜色编辑器自动选中当前生效的浅色或深色模式。
  • 高级筛选 — 底部状态栏右侧以文字标识文件大小与修改日期筛选入口，支持常用预设和自定义范围，启用数量以紧凑徽标显示。
  • 键盘工作流 — Enter 可配置为打开或重命名，方向键可移动选中项，选择结果后焦点可进入列表继续操作。
  • 拖放文件 — 可将搜索结果直接拖到 Finder、VS Code、Xcode 或其他应用。
  • 右键菜单 — 支持打开、在 Finder 中显示、复制完整路径等常用操作。
  • Cmd+Click 定位 — 快速在 Finder 中显示目标文件。
  • 中英文界面 — 应用界面、菜单、设置和帮助支持简体中文与英文。

设置与部署

  • 分级权限引导 — 首次启动可选择无需完全磁盘访问的快速开始，或授权后的全盘搜索。
  • 开机启动 — 支持登录后自动启动，并可最小化后台运行。
  • 快捷键设置 — 可自定义全局唤出快捷键。
  • 内容搜索设置 — 管理全文索引范围和资源限制。
  • GUI 应用 — SwiftUI 菜单栏应用，面向日常桌面使用。
  • 本地构建与 DMG 发布 — 支持 Xcode 本地构建与 DMG 打包；发布脚本可分别产出 arm64 和 Intel DMG。
  • RE2 依赖嵌入 — 构建流程会准备并嵌入 RE2/Abseil dylib，验证主应用、MCP 程序和依赖库不再引用 Homebrew 绝对路径。

自动化与 AI 工具集成

  • 本地 HTTP API — 默认监听 `localhost:19860`，支持文件搜索、内容搜索、最近文件、状态和内存信息接口。
  • HTTP 服务健壮性 — 仅绑定回环地址，支持并发连接，启动端口短暂占用时自动重试，并限制异常请求体大小。
  • HTTP API 鉴权 — 可选启用当前用户专属的本地 Bearer token；无论是否启用，始终拒绝非回环 Host 和浏览器 Origin 请求。
  • MCP Server — 内置 Model Context Protocol 支持，可供 Claude Code、Cursor、Claude Desktop 等 AI 工具调用。
  • 一键配置 MCP — 应用菜单中提供 MCP 集成入口。
  • AI 可用工具 — 提供 `search_files`、`search_content`、`recent_files`、`index_status` 等能力。

性能与可靠性

  • C++20 核心引擎 — 搜索、扫描、索引、持久化由 GUI 中的唯一引擎驱动，CLI 和 MCP 通过本机 API 查询。
  • SoA 列式数据布局 — 提升大规模候选过滤时的缓存局部性。
  • 路径字符串驻留 — 目录路径使用表索引复用，降低百万文件规模下的内存占用。
  • v6 Flat SoA 两阶段索引 — 启动先加载基础记录，后台再构建 Trigram、拼音、路径、扩展名、CJK bigram 和最近文件索引。
  • Phase 2 可靠性保护 — 后台索引构建期间新增/更新记录先进入基础数据，索引切换时回放变更；内存不足时跳过 Phase 2 避免半成品索引。
  • ARM NEON SIMD — 对不可索引加速的字符串匹配路径使用向量化优化。
  • APFS Firmlink 去重 — 处理 macOS System/Data 卷合并路径带来的重复遍历问题。
  • Unicode 查询归一化 — 对非 ASCII 查询尝试常见 NFC/NFD 变体，适配 macOS 文件名表示。
  • FSEvents 安全重放 — 规范化排除路径、过滤自身缓存事件，并在停止监听时排空回调队列，降低竞态和误重扫风险。
  • 自动化测试覆盖 — 覆盖扫描、查询、持久化、内容索引、HTTP、MCP、并发和内存安全等模块。
