MacEverything

macOS 上的文件名极速搜索工具，类似 Windows Everything。
Fork 自 joshua-wu/MacEverything，针对中文环境和日常使用做了大量改进。

下载最新版 DMG

仅支持 Apple Silicon (arm64)

主要特性

  • 极速搜索 — 500 万文件索引 <1s，查询 ~10ms
  • 拼音首字母搜索 — 输入 zm 找到「桌面」
  • 丰富过滤器 — 扩展名、大小、日期、路径、正则、文件内容
  • 文件操作 — 改名、删除、拷贝、预览、在终端打开
  • 中文界面 — 完整简体中文本地化
