使用说明

搜索语法

平时直接输入文件名、路径或拼音首字母即可。
需要进一步筛选时，再使用下面的搜索语法。

常用搜索：直接输入就能查找

不必记住语法。输入你记得的名称或路径，结果会随输入更新；默认不区分大小写。

报告
输入文件名的一部分，查找名称或路径中包含“报告”的文件。
report pdf
用空格分隔多个关键词，查找同时匹配这两个词的结果。
Downloads
输入文件夹名，也能找到路径中包含它的文件。
dl
中文名称可用拼音首字母查找，例如“电力”。
常用搜索 关键词与运算 正则表达式 文件类型 大小与长度 日期 路径 匹配方式 文件内容

关键词与布尔运算

readme
文件名或完整路径包含 readme；默认不区分大小写。
report pdf
空格表示 AND：两个词都要匹配，可以分别命中文件名和路径。
"exact phrase"
匹配包含空格的连续短语。
A | B
OR：匹配任意一个条件；使用竖线，不使用单词 OR。
!draft
NOT：排除匹配 draft 的结果。
<hello | world> .txt
尖括号分组。优先级：NOT → AND → OR。
*.txt · test* · file?.pdf
通配符 * 匹配零个或多个字符，? 匹配一个字符。

中文名称支持拼音首字母，例如 dl 可匹配“电力”。

修改日期

dm:today · dm:yesterday
今天 / 昨天。dm: 的完整写法是 datemodified:。
dm:thisweek · dm:lastweek
本周 / 上周；一周从星期日开始。
dm:thismonth · dm:lastmonth
本月 / 上月。
dm:thisyear · dm:lastyear
今年 / 去年。
dm:last7days · dm:last3months
最近 N 天、周、月或年：lastNdays / weeks / months / years。
dm:2026 · dm:2026-01 · dm:2026-01-15
指定年、月或日期。
dm:>=2026-01 · dm:>2026-01
从 2026 年 1 月起 / 2026 年 1 月之后。也支持 <、<=。
dm:2026-01..2026-06
包含 1 月到 6 月；可省略一端，如 dm:..2026-06。

日期按本机时区解释。兼容 dc:/datecreated: 和 da:/dateaccessed:，但目前均按修改时间匹配，不能用于区分创建或访问时间。

大小、名称长度与目录深度

size:>1mb · size:>=1gb
大于 1 MB / 至少 1 GB。也支持 < 和 <=。
size:1024
大小等于 1024 字节。
size:100kb..5mb
包含两端的大小区间，用两个点连接。
size:1gb.. · size:..5mb
省略一端，表示无上限或从零开始。
len:>10 · len:5..20
文件名长度，按 UTF-8 字节数计算。
depth:<3
所在目录路径中的 / 数量，小于 3。

大小单位：b、k/kb、m/mb、g/gb、t/tb；按 1024 进位，支持 1.5mb。比较与区间语法也适用于 len:、depth:。

匹配方式

case:Makefile
区分大小写匹配这个词。
nocase:readme
不区分大小写匹配这个词。
ww:hello · wholeword:hello
文件名中的完整单词匹配。
wfn:readme.md · wholefilename:readme.md
匹配整个文件名，包含扩展名。

可将匹配方式与其他条件组合，例如 case:Makefile path:src。

正则表达式

regex:^test_.*\.py$
查找以 test_ 开头、以 .py 结尾的匹配文本。
ext:py regex:^test_
筛选条件放在 regex: 之前；其后的全部文本都作为正则，包括空格和 |。
^ · $ · .
文本开头、文本结尾、任意字符。
\. · \\
转义：匹配字面上的点或反斜线。
[abc] · [^abc] · [a-z]
字符集合、排除集合和范围。
\d / \D · \w / \W · \s / \S
数字、单词字符、空白；大写形式表示相反集合。
* · + · ?
重复零次或多次、一次或多次、零次或一次。
{3} · {2,} · {2,5}
重复指定次数、至少两次、两到五次。
(foo|bar) · (?:foo|bar)
分组与交替；(?:...) 为非捕获分组。

使用 RE2 语法，默认不区分大小写；不支持反向引用和环视。开启菜单中的“正则表达式”选项后，整个输入都按正则解析，不再解析普通过滤器、布尔运算或通配符。

路径筛选与路径查询

path:Downloads
完整路径（含文件名）包含 Downloads。
nopath:node_modules
排除完整路径包含 node_modules 的结果。
parent:/usr/local/bin
直接父目录必须与给定的完整路径相等。
src/main
文件名包含 main，父路径包含 src。
/abc/def/
查找 abc 下名称匹配 def 的目录。
/abc/def/*
列出 abc 下 def 目录的直接子项。
/abc/*/def
非相邻路径段：中间允许有其他目录。
~/Documents/*.pdf
查询开头的 ~ 展开为当前用户的主目录。

路径段保持子串匹配语义，从右往左匹配。过滤器参数在空格处结束；含空格或特殊运算符的复杂路径，宜用普通短语或正则表达式查找。

文件类型

ext:pdf
按扩展名筛选。
ext:cpp;h;hpp
多个扩展名用分号分隔。
file: · type:file
仅文件。
folder: · type:folder · type:dir
仅目录。
audio: · video: · pic:
按音频、视频或图片扩展名筛选。
doc: · exe: · zip:
按文档、应用/脚本/安装包或压缩包扩展名筛选。

例如 ext:pdf report 或 video: size:>1gb。类型宏按扩展名识别，不检查文件内容。

文件内容

infile:TODO · content:TODO
搜索文件内容，两个前缀等价。
ext:cpp infile:TODO
在 C++ 文件内容中查找 TODO。

先在应用的“内容设置”中启用内容索引，并设置文件类型和最大文件大小。仅搜索已纳入内容索引的文件。
