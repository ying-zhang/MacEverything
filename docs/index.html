MacEverything：macOS 快速文件搜索工具（fork自joshua-wu）

2026-05-21https://ying-zhang.cn/misc/2026-maceverything/

macOS 的极速文件搜索工具，类似 Windows 系统的Everything。Fork 自 joshua-wu/MacEverything，增加了一些改进。

主要特性

  • 极速搜索 — 500 万文件索引 <1s，查询 ~10ms
  • 中文界面 — 完整简体中文本地化
  • 拼音首字母搜索 — 输入 zm 找到「桌面」
  • 丰富的过滤器 — 扩展名、大小、日期、路径、正则、文件内容
  • 搜索结果快捷操作 — 改名、删除、拷贝、预览、在终端打开
  • 可配置 — 索引范围、快捷键、MCP 集成、低内存模式等
