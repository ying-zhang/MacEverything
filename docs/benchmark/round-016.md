## 3. 问题分析

### 整体诊断

R16 全面回升是 **新会话冷启动 + 大量 WAL（3,319 条）** 的典型表现。所有路径都受到 VM 页面缓存冷启动影响，尤其是：

- 线性路径：+122%~+381%（paged index 页面未缓存）
- SOA 路径：+122%（结构化数组未缓存）

| P16 flush 后组合劣化 | Medium | 无 flush | — |

### P17（New, Medium）— `wild:*.txt` glob-trigram 冷启动异常

**现象**：`wild:*.txt` 在 R16 新会话冷启动时延迟 115.8ms（正常 0.1ms，+115,700%）。

**日志证据**：`total=115ms, trigram=115ms, candidates=0, results=0`。全部时间花在 trigram 查找上。

**根因假说**：glob-trigram 路径首次访问 trigram hash map 时触发大量 VM page fault，因为 nameTrigramIndex_ 在冷启动时完全不在物理内存中。

**影响**：仅首次查询受影响，后续查询恢复至 0.1ms。属一次性开销。

**建议**：低优先级。如果实施 P0 的 flush 后预热（建议 6），可附带预热 trigram index。
